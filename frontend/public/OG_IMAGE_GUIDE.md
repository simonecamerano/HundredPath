# Open Graph Image

Create a 1200x630px image for social media sharing.

## Requirements
- **Dimensions**: 1200 x 630 pixels (1.91:1 aspect ratio)
- **Format**: PNG or JPG
- **File size**: < 8 MB (recommended < 300 KB)
- **Filename**: `hundredpath-og.png`
- **Location**: `/frontend/public/hundredpath-og.png`

## Design Guidelines

Include these elements:
1. **Game title**: "HundredPath"
2. **Tagline**: "The 10x10 Logic Game"
3. **Visual**: Game grid or gameplay screenshot
4. **Brand colors**: Use your purple theme (#7950f2)
5. **Contrast**: Ensure text is readable on all backgrounds

## Tools to Create

- **Figma**: Free design tool (recommended)
- **Canva**: Quick templates
- **Photoshop**: Professional design
- **GIMP**: Free Photoshop alternative

## Testing

After creating the image, test it:
1. Add to `/frontend/public/hundredpath-og.png`
2. Deploy to Vercel
3. Test with:
   - [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/)
   - [Twitter Card Validator](https://cards-dev.twitter.com/validator)
   - [LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/)
